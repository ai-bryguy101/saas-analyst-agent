# ADR-0002: A fictional SaaS company, in a public repository

- Status: Accepted
- Date: 2026-11-10
- Decider: Bryan

## Context
The agent needs a large, messy enterprise data estate to work over, and the
work needs to be visible to employers.

## Decision
The fictional company is a SaaS business (Brindlecove Software). The repo is
public at `ai-bryguy101/saas-analyst-agent`, kept separate from Hangpost.

## Consequences
All data must be synthetic and safe to publish. Anything in the repo can be
read by anyone, so no secrets are ever committed.
